# 2026-09

- 2026-09-01 · [功能] 为 `pi-optimization` 增加 fullscreen 鼠标滚轮优化：原生 Windows 默认将每次 Pi fullscreen 滚轮事件按 3 行处理，支持 `/fullscreen-scroll` 与 `settings.json` 中的 `fullscreen-scroll` 段即时调整或关闭；只在 Pi 暴露预期运行时 seam 时启用，并在会话关闭时恢复。范围：package:pi-optimization、context:pi-optimization
  原因：Pi 0.84 的 `TuiAltScreen` 默认 `wheelScrollLines` 为 1，ConPTY + PowerShell 7 下 fullscreen 滚轮明显慢于终端原生滚动；Pi ExtensionAPI 尚未公开该参数。
  当前依据：[pi-optimization 包架构页](../architecture/packages/pi-optimization.md)、[Pi 优化上下文](../requirements/contexts/pi-optimization.md)。
  证据：`packages/pi-optimization/src/fullscreen-scroll.ts`、`packages/pi-optimization/extensions/index.ts`、`packages/pi-optimization/test/fullscreen-scroll.test.ts`、Pi `@earendil-works/pi-tui` 的 `TuiAltScreen.routeWheel`。

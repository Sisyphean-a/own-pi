# LSP 反馈上下文

## 作用域

- 上下文：`lsp-feedback`
- 实现包：`pi-lsp-feedback`
- 入口与证据：`packages/pi-lsp-feedback/extensions/index.js`、`src/diagnostic-service.js`、`src/lsp-client.js` 与 `README.md`

## 术语

- **诊断反馈**：代理成功执行 `write` 或 `edit` 后，由匹配的语言服务器生成的错误和警告。
- **已确认结果**：拉取诊断响应，或携带当前文档版本的 `publishDiagnostics` 通知。只有这种结果能证明文件干净。
- **未确认结果**：不带版本的诊断发布、超时，或没有新的诊断发布。它必须提醒代理不能将文件视为干净。
- **不可用结果**：没有匹配的工作区标记、文件不可读，或语言服务器不能启动、安装或保持可用。
- **受信任项目覆盖项**：Pi 将项目标为受信任时才读取的可选 `.pi/lsp-feedback.json` `servers` 条目；它可以替换内置命令、参数、根目录标记、回退行为，或禁用该服务器。

## 稳定规则

- 非错误的 `write` 或 `edit` 结果会触发反馈；不受支持的文件会被忽略。
- 反馈在一轮内聚合，并在轮次结束时作为引导上下文发送；已确认且干净的文件不增加上下文。
- 只报告严重级别 1（错误）和 2（警告）的诊断，每轮最多 20 条。
- 扩展只观察和报告诊断。它不修改用户源码、不格式化代码、不应用修复，也不扫描项目；Vue、TypeScript、HTML 与 Pyright 服务器由包携带，只有可信项目中的 Go 文件可触发扩展托管安装 `gopls`。
- 内置支持 Vue、TypeScript/JavaScript、Go、Python 和 HTML。Go 文件需要 Go 模块或工作区标记；其他内置服务器在没有特定标记时可以回退到 Pi 工作区。

## 非目标

本上下文不承诺系统具备 Go 运行时或 `gopls` 安装能成功。包内 Node 服务器应随扩展存在；缺少 Go 运行时、安装失败或其他服务器启动失败会明确报告为不可用，而不会被当作干净结果。

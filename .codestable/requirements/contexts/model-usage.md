# 模型用量统计

拥有本机 Pi 的模型消费统计，不拥有接入厂商账单、套餐或模型调用策略。

## 通用语言

- **模型用量**：请求已上报的输入、缓存与输出计数；不等于当前上下文占用。
- **命中**：缓存读取 token；**未命中输入**：普通输入与缓存写入 token 之和；**输出**：包含推理子集的输出 token。
- **官方价估算**：以明确模型匹配到的官方 API 标准按量价估算的 USD 费用，不是实际扣款或订阅月费。
- **离线报表**：生成时内嵌数据的单文件 HTML 快照，不自动连接数据库或刷新。

## 稳定规则

- 统计按模型归集，不区分来源或接入厂商。同一明确模型跨厂商合并，不同版本、档位及 Codex 变体分别保留；自定义名称仅通过显式别名匹配。
- 默认为 GPT、DeepSeek、Claude 提供有官方依据的价格。缓存写入单独计价；推理 token 和 1h 写入分别是输出和缓存写入的子集，不能重复加总。
- 每条记录固定采集时的价格版本和费用，后续改价不重算。历史导入无法恢复原价时按导入时价估算并标注；默认估算不包含特殊服务档优惠、附加费或工具单独收费。
- 未知模型、价格、计数或耗时明确标记未知，不猜测、不当成零或免费。失败/取消请求有已上报用量也计入；核心合并摘要只保存可证实字段。
- 消耗不随会话回退或删除撤销；恢复、fork 复制及重复导入不重复累计。新请求持续采集，旧会话只手动导入。
- 时间存 UTC，按本机时区展示。命令 `/token` 提供今日、本月、累计概览；`/token html` 默认按日/模型汇总，指定日期范围可包含请求级明细。
- 数据只存本机用户目录，长期保留、不自动删除；不存提示词、回答、密钥或项目路径。
- 性能与低常驻内存优先于账单级精确：不逐 token 处理、不全量扫描、不加载全部历史。待写数据（含在途）约 256 KiB 上限、约 1 秒合批；满时丢新记录，IO 失败暂停并释放缓冲；查询暴露已知损失，修复后显式恢复，正常退出尽量刷盘。
- 仓库内调用点只提供可选的请求完成通知；统计扩展缺失或失败不影响模型响应。不全局包装运行时；第三方私有调用不保证覆盖。
- HTML 不启动服务器、不自动读取数据库，不默认装入全部历史请求。零开销、零损失及未上报消耗不属于保证范围。
